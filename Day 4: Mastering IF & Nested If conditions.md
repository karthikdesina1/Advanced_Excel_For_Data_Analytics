## 💡 Technical Reference: Logic Progression

| Concept | Syntax Example | Core Purpose & Application |
| :--- | :--- | :--- |
| **1. Foundational IF** | `=IF(Score>=50, "Pass", "Fail")` | Evaluates a single condition to split data into binary outcomes. |
| **2. AND Logic** | `=IF(AND(T1>=70, T2>=70), "Pass", "Fail")` | Enforces multiple criteria to be simultaneously true. |
| **3. OR Logic** | `=IF(OR(E1>5, E2>5), "Qualified", "Not")` | Triggers a positive result if any single condition is met. |
| **4. Nested IF** | `=IF(S>=90, "A", IF(S>=80, "B", "C"))` | Handles tiered classifications, grading, or multi-level risk scaling. |
| **5. Industry Datasets** | Cross-column matrix comparison | Automates budget variance tracking, SLA compliance, and server uptime alerts. |
