# 📊 Recap: Basics of Excel

## 📌 Overview
Microsoft Excel is a fundamental tool for organizing, managing, analyzing, and presenting business data.

This module revisits the essential Excel concepts that form the foundation for formulas, Pivot Tables, dashboards, and advanced data analytics.

**Learning Path:** Fundamentals → Navigation → Formatting → Formulas → Pivot Tables → Dashboards → Business Insights

---

## 1. Excel Fundamentals & Core Concepts

### What is Microsoft Excel?
Excel is spreadsheet software used for data entry, calculations, reporting, analysis, and visualization.

### Essential Terminology

| Concept | Description |
|---|---|
| Workbook | An Excel file containing worksheets |
| Worksheet | A spreadsheet within a workbook |
| Row | Horizontal collection of cells |
| Column | Vertical collection of cells |
| Cell | Intersection of a row and column |
| Cell Reference | Address such as A1 or B5 |
| Range | Group of cells such as A1:D20 |
| Active Cell | Currently selected cell |

### Practical Example
A company maintains sales data containing:
- Order ID
- Product
- Region
- Quantity
- Revenue
- Date

Excel allows analysts to organize and examine this information.

## 3. Excel Ribbon & Menu Hierarchy

The Ribbon organizes Excel commands into tabs and groups.

### Main Ribbon Tabs
| Tab | Primary Purpose |
|---|---|
| Home | Formatting and editing |
| Insert | Tables, charts and PivotTables |
| Page Layout | Page and print settings |
| Formulas | Functions and formula auditing |
| Data | Sorting, filtering and validation |
| Review | Comments and protection |
| View | Navigation and workbook display |
| File | Workbook and application management |

### Ribbon Hierarchy
```text
EXCEL RIBBON
     ↓
TAB
     ↓
GROUP
     ↓
COMMAND
     ↓
ACTION
```

Example:
**Home → Alignment → Wrap Text**

Understanding this hierarchy reduces time spent searching for commands.

## 6. Basic Excel Formulas

Excel formulas begin with an equals sign.

### Addition
```excel
=A2+B2
```

### Multiplication
```excel
=B2*C2
```

### SUM
```excel
=SUM(D2:D100)
```

### AVERAGE
```excel
=AVERAGE(D2:D100)
```

### COUNT
```excel
=COUNT(D2:D100)
```

### MAX and MIN
```excel
=MAX(D2:D100)
=MIN(D2:D100)
```

### Cell References
- Relative: A2
- Absolute: $A$2
- Mixed: $A2 or A$2

Understanding references is essential when copying formulas.
